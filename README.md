# Поличка 2.0 — безкоштовна основа для Vercel та Telegram Mini App

Оновлена версія наданого HTML. Статичний сайт, без збірки та платних залежностей. **Не деплоєно автоматично.**

## Уже працює

- Запаси, кількості, категорії, пошук, пороги поповнення, ручні покупки, терміни, QR, JSON-імпорт/експорт — функціонал оригіналу.
- Сканування товарів камерою або введенням EAN/GTIN. Назви й категорії з **Open Food Facts**; пошук може не знайти конкретний товар. Камера та завантаження модулів потребують HTTPS/інтернету.
- OCR чеків **Tesseract.js** локально у браузері: фотографія → виділення рядків → редагування/вибір → підтвердження → додавання. Розпізнавання цін/назв **може помилятися**; кількість із чека за замовчуванням 1 і після імпорту її треба перевірити. Фото не завантажується на наш сервер.
- OCR фото дати придатності → список кандидатів → обов'язкове ручне підтвердження та вибір продукту. Саме по собі це не гарантує правильності чи безпеки їжі.
- Офлайн-підбір рецептів за збігом назв інгредієнтів, автоматичне додавання відсутніх продуктів до покупок.
- Витрати за збереженими чеками, бюджет, журнал дій, локація зберігання, цінник і штрихкод у картці.
- PWA: маніфест, базовий service worker для офлайн-оболонки (AI/OCR-моделі та довідник товарів вимагають мережу, якщо вони ще не завантажені браузером).
- Опціональна серверна функція `/api/ai`: NVIDIA NIM з ключем лише на сервері, перевірка підписаного Telegram `initData`, allowlist Telegram ID.

## Як викласти на Vercel

1. Створи приватний GitHub-репозиторій і поклади **вміст цієї папки** у корінь. `index.html` має бути на верхньому рівні, `api/ai.js` у папці `api`.
2. Vercel → Add New Project → Import Git Repository → Framework: **Other** → Build Command: **порожньо**, Output Directory: **порожньо** → Deploy.
3. Відкрий адресу `https://<project>.vercel.app` та протестуй ручне додавання. Vercel безкоштовний Hobby підходить для особистого **некомерційного** використання, є ліміти.
4. Для Telegram Mini App створити бота через BotFather та налаштувати Menu Button / Web App URL на цю адресу.
5. **Лише для NVIDIA**: отримай NIM ключ на https://build.nvidia.com, переконайся, що вибрана модель доступна саме тобі для виклику API, додай до Vercel Environment Variables чотири змінні з `.env.example`. Redeploy. Для запиту відкривай додаток **саме через Telegram**, а Telegram ID додай до allowlist.

### Чого безкоштовна HTML-версія не робить

- **Немає міжпристроєвої синхронізації.** Запаси та історія — це `localStorage` на конкретному пристрої. QR на холодильнику лише відкриває додаток; в сім'ї дані не будуть спільними без БД та авторизації.
- **Немає фонових сповіщень.** Перевірка термінів працює при відкритті екрана, Telegram-бот/серверні cron і синхронізація поки не підключені.
- **NVIDIA не є безлімітною чи гарантовано безкоштовною для продакшну.** Без чинного безкоштовного API-доступу кнопка повертає коректну помилку, локальні рецепти працюють.
- OCR не може з чека надійно визначити дату придатності, кількість і всі можливі товарні назви. Перед підтвердженням потрібно перевіряти.
- Vercel Hobby допускає некомерційне особисте використання, а не безкоштовний комерційний SaaS.

### Безпека

Не вставляй `NVIDIA_API_KEY` у HTML/JS або GitHub. Власникам доступ до AI дає `ALLOWED_TELEGRAM_IDS`; сервер перевіряє криптографічний підпис Telegram WebApp. Рівень запитів у serverless in-memory обмежений лише орієнтовно — для публічного запуску знадобиться **розподілений rate limit** і квотування.

### Розробка

Для локального перегляду: `python -m http.server 3000` у корені (на localhost камера може працювати). Для тестування `/api/ai` локальний Python сервер не підходить: потрібен `vercel dev` або деплой у Vercel.
